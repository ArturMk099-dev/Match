# 🃏 Match Game

A fun card matching game where you need to find matching pairs of cards.

## 🎮 How to Play
- Click on a card to flip it
- Find the matching pair
- Each correct match gives you points
- Match all cards to win!

## ✨ Features
- Card matching logic
- Score system
- Responsive design for mobile

## 🛠 Technologies
- HTML
- CSS
- JavaScript
